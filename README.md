CMP5361 - Task 1: Hex, Memory and Stack Calculator

Requirements
Python 3.11 or higher

how to run the program

python programA.py

running the tests 

python -m unittest testA.py -v


What each option does

Option

1) Converts a decimal number to hex, 16-bit binary and signed interpretation

2) Splits a number into two bytes (little-endian) and writes/reads from memory

3) Stores a string as ASCII bytes with a null terminator and prints a memory dump

4) Calculates an array element address and supports reading or writing to it

5) Shows a simplified stack frame layout with register view

0) Exits the programme
